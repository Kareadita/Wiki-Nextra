# Comics (Flexible)

Make sure you understand the [folder requirements](/guides/scanner#file-layout) of Kavita first.

Comic (Flexible) is the library type from before the [Comic](/guides/scanner/comicvine) type was introduced. If your files have full metadata and series are combining when you don't want them to, consider the Comic type.

## How this library reads a file

- **Series:** from the file name, always. Unlike Manga, this library never uses the folder name unless the file has an `SP` marker. Whatever is left of the name becomes the series, so `Saga/005.cbz` is a series named `005`. **Start every file with the series name.**
- **Volume and chapter:** from the file name.
- **No volume and no chapter:** the file is a [special](/guides/scanner/managefiles#specials), in a series named after the file.
- **Metadata:** `ComicInfo.xml` in a `.cbz`, `.cbr`, `.cb7` or `.cbt` file [beats the file name](/guides/scanner/managefiles#using-metadata).

## A good structure

```
Library Root
  ┖── Series Name
      ┠── Series Name #1.cbz
      ┠── Series Name #2.cbz
      ┠── Series Name v03 c01.cbz
      ┖── Specials
        ┖── Series Name Annual SP01.cbz
```

## Markers that work in Manga but not here

This library has its own rules, so some [Manga markers](/guides/scanner/managefiles#volumes) go wrong.

| File | What you get | Use instead |
|---|---|---|
| `Saga Volume 01.cbz` | A series named `Saga Volume` | `Saga v01.cbz` or `Saga Vol. 1.cbz` |
| `Saga c7.cbz` | A special in a series named `Saga c7` | `Saga #7.cbz` or `Saga 007.cbz` |
| `Saga - Ch. 5.cbz` | A series named `Saga - Ch.` | `Saga - Chapter 5.cbz` |
| `Saga Issue 5.cbz` | A series named `Saga Issue` | `Saga Issue #5.cbz` |
| `Saga 001-006.cbz` | Chapter 1 only | `Saga v01 c001-006.cbz` |
| `Saga S01.cbz` | A special in a series named `Saga S01` | `Saga v01.cbz` |
| `Saga 第25话.cbz`, `Saga 시즌2.cbz` | A special in a series with that whole name | Set `Series` and `Number` in [metadata](/guides/scanner/managefiles#using-metadata) |
| `Saga 第2卷.cbz` | Volume 2, in a series named `Saga 第2卷` | Set `Series` in [metadata](/guides/scanner/managefiles#using-metadata) |

## Keeping runs apart

Anything in `()` or `[]` is removed from the series name, so `Fables (2004)` and `Fables (1989)` would both be the series `Fables`. Put the year in `{}` to keep it:

| File | Series | Chapter |
|---|---|---|
| `Fables (2004) 022.cbz` | Fables | 22 |
| `Fables {2004} 021.cbz` | Fables `{2004}` | 21 |

If you have many runs, the [Comic](/guides/scanner/comicvine) library type does this for you.

## Marking a comic as a special [#marking-a-comic-as-a-special]

Words like `Annual`, `TPB`, `Omnibus` or `One Shot` in a name don't make a file a special, and they split it away from the main series:

| File | Series | Result |
|---|---|---|
| `Batman Beyond Annual.cbz` | Batman Beyond Annual | A special, in a separate series |
| `Batman Beyond Annual #001.cbz` | Batman Beyond Annual | Chapter 1, in a separate series |
| `Batman Beyond Annual SP01.cbz` | Batman Beyond | A special in the main series |
| `Specials/Batman Beyond Annual SP02.cbz` | Batman Beyond | A special in the main series |

There are two ways to make a file a special in the main series:

1. Add an `SP01`, `SP02`, etc. marker to the file name, in capitals. The series then comes from the folder. See [Specials](/guides/scanner/managefiles#specials).
2. Set the [`Format` tag](/guides/metadata/comics#format) in the file's `ComicInfo.xml` to a recognized value, written exactly as listed: `Annual` works, `annual` doesn't. This is the better choice if you can embed metadata. Also set `Series`, or the file keeps the series from its name.

| File | Tags in `ComicInfo.xml` | Series | Result |
|---|---|---|---|
| `Batman Beyond Annual #002.cbz` | `Series` Batman Beyond, `Number` 2, `Format` Annual | Batman Beyond | A special |
| `Batman Beyond Annual #002.cbz` | `Series` Batman Beyond, `Number` 2 | Batman Beyond | Chapter 2, mixed in with the main issues |

<Callout type="info">
	A file with `Format` set this way is a special without a number, so its name is what shows. See the full list of values on the [ComicInfo metadata page](/guides/metadata/comics#format).
</Callout>
