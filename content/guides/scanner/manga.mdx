# Manga

Make sure you understand the [folder requirements](/guides/scanner#file-layout) and the [naming rules](/guides/scanner/managefiles) first. That page has every volume and chapter marker a Manga library accepts.

## A good structure

```
Library Root
  ┖── Series Name
      ┠── Series Name v01.cbz
      ┠── Series Name v02.cbz
      ┠── Series Name v03.cbz
      ┖── Specials
        ┖── Series Name Omakes SP01.cbz
  ┖── Series Name 2
      ┠── Series Name 2 Vol.01 Ch.1.cbz
      ┠── Series Name 2 Vol.01 Ch.2.cbz
      ⋮
      ┖── Series Name 2 Vol.02 Ch.6.cbz
```

## How this library reads a file

- **Series:** from the file name. If there is none, from the [folder closest to the file](/guides/scanner/managefiles#files-with-no-series-in-the-name).
- **Volume and chapter:** from the file name. A folder is only used for these when the file name has no series either.
- **No volume and no chapter:** the file is a [special](/guides/scanner/managefiles#specials).
- **Metadata:** `ComicInfo.xml` in a `.cbz`, `.cbr`, `.cb7` or `.cbt` file [beats the file name](/guides/scanner/managefiles#using-metadata).

<Callout type="warning">
	A number in the title needs a marker after it. `Golgo 13 112.cbz` is series `Golgo`, chapter 13, but `Golgo 13 c112.cbz` is series `Golgo 13`, chapter 112. See [Numbers in the series name](/guides/scanner/managefiles#numbers-in-the-series-name).
</Callout>
