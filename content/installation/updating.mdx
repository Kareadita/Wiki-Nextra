# Updating 

How you update Kavita is dependent on how you installed it. 

Kavita is built as a stand-alone (portable) program. That means there is no official installer or uninstaller. 

Check out the guides for [docker](/installation/updating/updating-docker) and [native installs](/installation/updating/updating-native).
